# Design Patterns

Petit projet Java pour illustrer les concepts de design patterns et servir de base pour des démonstrations ou des exercices.

## Présentation

Ce dépôt contient une application Java simple démarrant depuis le fichier `src/Main.java`.

## Structure du projet

```text
.
├── src/
│   └── Main.java
├── README.md
└── .gitignore
```

## Prérequis

- Java JDK 8 ou plus récent
- Un terminal ou une IDE Java (IntelliJ IDEA, Eclipse, VS Code)

## Lancer le projet

Depuis la racine du projet :

```bash
javac src/Main.java
java -cp src Main
```

Si votre classe contient une méthode `main` dans le bon format Java, la commande affichera la sortie du programme.

## Exemple de méthode principale

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("hi");
    }
}
```

## Objectif du projet

Ce dépôt peut être utilisé pour :

- apprendre les design patterns
- tester des concepts Java de base
- servir de point de départ pour des exemples plus avancés
